# Installation of Selenium 

Execute `sudo dnf install gcc gobject-introspection-devel cairo-gobject-devel pkg-config python3-devel gtk4` to install the build dependencies and GTK

[setup KDE builder](https://develop.kde.org/docs/getting-started/building/kde-builder-setup/)

After having setup kde-builder also install kf6-kwindowsystem-devel, kf6-kcoreaddons-devel, kwayland-devel, kpipewire-devel
