\section{Laborary Setup for measuring software}

\begin{itemize}
 \item Power meter - recommended: Gude Expert Power Control 1202 Series, which can synchronously measure power usage and provide power to the tested computers.
 \item Computer 1:

    Is used to process the date, received from the power meter.
\item Computer 2:

    This is the testing machine, where the programs are executed by scripts and where the data about power cosumption is gained from. It is called the ``SUT - system under test''



\end{itemize}
